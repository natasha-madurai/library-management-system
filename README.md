Library Management System



A simple Library Management System made using \*\*Python, Flask, HTML, CSS and MySQL\*\*.



\## Features



\* Add Book

\* View Books

\* Edit Book

\* Delete Book

\* Search Book

\* Store book details in MySQL



\## Technologies Used



\* HTML

\* CSS

\* Python

\* Flask

\* MySQL

\* XAMPP



\## How to Run



1\. Start \*\*MySQL\*\* in XAMPP.

2\. Open the project folder.

3\. Install Flask:



```bash

pip install flask

```



4\. Install MySQL connector:



```bash

pip install mysql-connector-python

```



5\. Run:



```bash

python app.py

```



6\. Open:



```text

http://127.0.0.1:5000

```
